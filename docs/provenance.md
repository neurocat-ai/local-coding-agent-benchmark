# Provenance

The source workspace describes `demo/guard-erp` as a synthetic teaching project based on common security-company ERP workflows. The fixture contains no customer records, organization names, production endpoints, or external-service integration.

The repository owner confirmed on 2026-09-27 that the team created the fixture for this benchmark. It contains no client code or data and may be included in the public research case.

The available project mirror does not include the original repository's Git history, so this public repository starts with a new, sanitized history. Keep this provenance record with the fixture.
