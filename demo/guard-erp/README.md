# Guard ERP Demo

Безопасный учебный проект по мотивам типовых процессов ERP для охранных предприятий. В нём нет рабочего кода или данных заказчика.

## Запуск

```bash
dotnet restore
dotnet test
dotnet run --project src/GuardErp.Api
```

API после запуска: `http://localhost:5080`.

Задание конкретного прогона находится в корневом файле `TASK.md`. Скрипт подготовки
автоматически подставляет одну из задач ERP-001, ERP-003 или ERP-004.
