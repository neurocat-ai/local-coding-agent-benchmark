# ERP-004: права на отчёт

Добавить роль `ReportViewer`: пользователь с этой ролью может читать отчёт по начислениям, но не может менять его.

Условия:

- добавь новую роль в существующую модель ролей;
- `ReportViewer` может вызвать операцию чтения отчёта;
- `ReportViewer` не может заменить или изменить отчёт;
- поведение `Administrator`, `PayrollManager` и `Supervisor` должно сохраниться;
- не обходи централизованную проверку прав внутри сервиса;
- добавь тесты для разрешённой и запрещённой операции новой роли и сохрани покрытие существующих ролей;
- выполни подходящие тесты и кратко опиши результат.
