# ERP-003: оплата переработки

Исправить расчёт оплаты смены: часы сверх восьми в пределах одной смены должны оплачиваться с коэффициентом 1,5.

Условия:

- первые восемь часов оплачиваются по обычной ставке;
- только часы сверх восьми оплачиваются по ставке 1,5;
- правило действует и для смен, переходящих через полночь;
- существующая проверка входных данных и публичный контракт должны сохраниться;
- добавь тесты для обычной, длинной и длинной ночной смены, включая границу в восемь часов;
- выполни подходящие тесты и кратко опиши результат.
